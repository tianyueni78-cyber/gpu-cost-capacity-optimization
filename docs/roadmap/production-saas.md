# 生产 SaaS 交付门槛

当前已验证本地统一入口、开发登录、租户项目选择、四产品路由、持久化任务、worker 和跨租户 RLS。后续按以下顺序推进，每阶段只在证据完成后升级状态。

1. **正式身份与前台**：输入为身份服务账号和域名；门槛是登录、会话撤销、租户隔离及审计通过。
2. **只读连接器**：先 Azure，再 AWS 与 Kubernetes/Prometheus；门槛是客户授权、凭据托管、增量同步及撤销测试。
3. **GPU Data**：门槛是真实脱敏数据完成对账和质量门禁。
4. **GPU Optimize**：门槛是客户确认约束，方案可复算并经人工审批。
5. **GPU Improve**：门槛是实施前后基线可比，收益与成本规避分列。
6. **GPU Forecast**：门槛是滚动回测优于朴素基线，并披露区间和容量风险。
7. **支付、SSO、合规与灾备**：依赖外部账号、合同和监管材料；代码完成不能替代真实验收。

尚未完成 AWS/Kubernetes 正式连接器、支付宝、企业 SSO、ICP备案、自动生产变更、生产监控和恢复演练。
