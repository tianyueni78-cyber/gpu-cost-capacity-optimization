# GPU 审计试点 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将三个已运行产品的导出串成可演示、可复算的一次 GPU 审计试点。

**Architecture:** 使用一个根级 Python CLI 读取现有 CSV 导出并生成行动交接文件和管理层总报告。产品内部代码保持独立，交接只通过文件完成。

**Tech Stack:** Python 标准库、现有 pandas 依赖、unittest。

**Spec:** `docs/superpowers/specs/2026-09-12-gpu-pilot-design.md`

## Global Constraints

- 不新增第三方依赖。
- 不自动修改生产资源。
- 受影响成本不转换为预计节省。
- 已验证收益与成本规避分列。
