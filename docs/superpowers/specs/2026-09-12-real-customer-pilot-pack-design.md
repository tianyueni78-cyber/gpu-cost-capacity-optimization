# 真实客户试点包设计

## 目标

提供一个可直接发给首批客户的文件包，让客户准备脱敏数据、完成 30 分钟共同核验，并收到范围清楚的结果和实验报价。

## 结构

只增加 `customer-pilot-pack/`：

- 四张与 GPU Data 字段契约一致的空白 CSV；
- 一份入口说明；
- 一份脱敏说明；
- 一份 30 分钟操作流程；
- 一份结果审核清单；
- 一份固定范围实验报价。

不增加网页、表单、数据库、账号系统或新依赖。客户文件继续在本地工具中处理。

## 商业边界

首轮报价是待真实客户验证的价格实验，不是正式定价决定。交付覆盖一个组织、一个连续 7–31 天期间、四张 CSV、最多 50 个 GPU 资源池，以及一次结果复核。产品不执行生产变更，不承诺节省，不包含 Forecast、采购谈判或长期监控。

截至 2026-09-12，Finout 和 CloudZero 均按客户环境规模与复杂度提供定制报价，而非统一公开价格。本试点用固定小范围和固定实验价降低首次采购的不确定性：

- https://www.finout.io/pricing
- https://www.cloudzero.com/pricing/

## 验收

- 四张模板的字段与产品 `TABLE_SPECS` 完全一致；
- 模板不包含真实或示例客户数据；
- 客户能从入口说明判断所需数据、范围和下一步；
- 脱敏说明区分必须保留、必须替换和不得提供的信息；
- 30 分钟流程含停止条件和可记录结果；
- 审核清单覆盖金额对账、数据质量、建议约束、收益口径和人工审批；
- 报价包含范围、交付物、周期、价格、付款节点、客户责任和排除项；
- README 能从仓库根目录直接定位该包。
