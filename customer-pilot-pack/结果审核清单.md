# 结果审核清单

审核人应为客户的基础设施负责人或其明确授权人。任何“未通过”都必须进入报告，不得口头跳过。

## 数据与范围

- [ ] 四张表属于同一客户、同一分析期间和同一币种；
- [ ] 账单净成本与客户原始账单差异小于 0.01 USD；
- [ ] 所有阻断项已解决；警告项已列入报告；
- [ ] 资源池关联率、成本归属率和遥测覆盖率已展示；
- [ ] 缺失数据保持缺失，没有静默填零。

## 指标与建议

- [ ] 库存、已分配、活跃数量和利用率没有混为同一指标；
- [ ] 每条线索可回到资源池、时间范围和来源记录；
- [ ] 低利用率没有直接写成可回收或可节省；
- [ ] 容量需求、最低备用、型号、区域和共享权限由客户确认；
- [ ] 无可行方案时展示缺口，没有自动放松硬约束；
- [ ] 同一资源的互斥方案没有重复计算。

## 金额与收益

- [ ] 受影响成本使用资源池实际费率；
- [ ] 受影响成本没有表述为预计或实际节省；
- [ ] 合同退出费用、不可取消承诺和实施成本已说明；
- [ ] 已验证收益只来自可比的行动前后数据；
- [ ] 成本规避与已验证收益分列；
- [ ] 任何节省数字都能由明细复算。

## 审批与交付

- [ ] 建议状态由客户决定；
- [ ] 批准行动有负责人、批准日期、执行日期和回滚条件；
- [ ] SLA 风险、数据限制和待验证问题出现在管理层报告；
- [ ] 产品未自动修改任何生产资源；
- [ ] 双方确认结果复核人、文件删除日期和下一步。

## 审核结论

- [ ] 可进入内部审批
- [ ] 补充数据后复核
- [ ] 仅作为调查线索
- [ ] 不采用
