## 固定范围

- 一个客户组织；
- 一个连续 7–31 天分析期间；
- 一套 GPU 资源、使用、账单和 SLA 数据；
- 最多 50 个 GPU 资源池；
- 一次数据可用性检查、一次 30 分钟共同分析和一次 45 分钟结果复核；
- 数据通过准入后 5 个工作日内交付。

## 交付物

- 数据质量与成本对账结果；
- GPU 成本、库存、活跃度和利用率基线；
- 可追溯调查线索；
- 满足客户确认约束的容量方案和风险说明；
- 建议 CSV；客户书面批准后另生成 GPU Improve 行动 CSV；
- 一份管理层 Markdown 报告；
- 一轮书面问题修订。

## 实验报价

**固定服务费：人民币 6,800 元。**

付款节点：数据可用性检查通过后支付 50%，交付结果复核完成后支付 50%。税费及发票安排由双方在开始前书面确认。

本价格用于验证客户是否愿意为可信 GPU 决策材料付费。它不是正式公开售价，完成三次真实报价后根据成交、拒绝原因和交付工时复核。

## 客户责任

- 按模板提供合法、准确且已脱敏的数据；
- 指定能确认账单、容量约束和 SLA 的负责人；
- 对建议作出待确认、待审批、推迟或不适用决定；
- 自行审批、执行和回滚任何生产变更。

## 不包含

- 自动接入云账号、Kubernetes 或监控系统；
- 自动修改或执行生产资源变更；
- GPU Forecast、长期容量预测或采购谈判；
- 多云迁移实施、模型性能调优和调度系统改造；
- 对节省金额、可用性或业务结果的保证；
- 超出一次书面修订的新增范围。

如果数据检查发现无法建立账单、资源和使用关联，双方先决定补数或结束试点；此时不启动正式分析，也不收取剩余款项。
