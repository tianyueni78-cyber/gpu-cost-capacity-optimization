# GPU Improve Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建一个可独立运行的 GPU Improve Streamlit 应用，跟踪优化行动并依据可比基线、行动类型、有效成本和 SLA 证据验证实际收益。

**Architecture:** 平台代码全部位于 `gpu-improve/`。纯 Python 领域模块负责数据契约、状态机、可比性、收益公式、重叠检查和报告；Streamlit 只负责交互；Supabase 只保存用户、行动、汇总指标和验证结果，原始 CSV 留在会话内。所有计算先通过纯函数测试，再接入数据库和页面。

**Tech Stack:** Python 3.11+、pandas 2.2+、Streamlit 1.40+、supabase-py 2.x、Supabase PostgreSQL/RLS、unittest

**Spec:** `gpu-improve/正式规格.md`

## Global Constraints

- 四个平台独立运行；GPU Improve 不导入其他平台目录中的 Python 模块。
- 原始账单和使用 CSV 不写入 Supabase，只保存 SHA-256 指纹、审计摘要和汇总指标。
- 潜在收益、批准收益、已验证收益和成本规避分别存储、分别展示。
- 缺少可比基线、适配公式或关键 SLA 时拒绝输出正式收益。
- 服务密钥不得进入浏览器、代码或 Git；数据库使用邮箱登录和 Row Level Security。
- 第一版不自动修改云资源，不实现企业组织、多人审批或 GPU Forecast 模型。
- 每项核心功能在 README 中标注专业依据、采用范围和未采用范围。

```python
def test_rightsize_normalizes_variable_cost_and_preserves_fixed_cost(self):
    result = verify_benefit(
        action(ActionType.RIGHTSIZE, implementation_cost_usd=100),
        baseline(variable_cost=8000, fixed_cost=2000, business_volume=1000),
        post(variable_cost=7200, fixed_cost=2000, business_volume=1200),
        allowed_high_confidence(),
    )
    self.assertEqual(result.counterfactual_cost_usd, 11600)
    self.assertEqual(result.realized_savings_usd, 2300)
```

公式解释：变动成本反事实为 `8000 / 1000 × 1200 = 9600`，固定成本保持 `2000`，扣除实际 `9200` 和实施成本 `100`，收益为 `2300`。

同时测试费率优化使用按需等价成本、型号替换要求性能可比、调度优化要求单位业务成本与 SLA、避免采购只产生成本规避。
