# GPU Improve 试点验证

## 目标

验证一名 GPU 平台或 FinOps 负责人能否在 30 分钟内独立完成收益证据闭环，而不是测试其是否会写代码。

## 30 分钟任务

1. 导入 `examples/actions.csv`，识别并修复一项字段问题。
2. 将行动从“已批准”推进至“待验证”，确认每次变化留下事件。
3. 分别完成“已验证”“负面影响”“无法验证”三类判断。
4. 检查基线范围、期间、币种、成本口径、业务量单位和证据等级。
5. 确认已验证收益、成本规避没有相加，SLA 负面影响未被隐藏。
6. 导出收益台账和管理层报告。

## 记录表

| 验收项 | 通过标准 |
|---|---|
| 独立完成 | 不依赖开发者解释即可走完四页 |
| 口径判断 | 能解释为何固定成本不随业务量缩放 |
| 风险识别 | 能发现重叠行动、不可比期间和 SLA 下降 |
| 结果可信 | 能从结论追溯至行动、基线、方法和原因 |
| 商业价值 | 能说明节省金额、风险及下一项管理决策 |

记录完成时间、求助次数、误判点和未理解术语。若用户必须查看数据库或源代码才能完成，视为产品流程失败。
