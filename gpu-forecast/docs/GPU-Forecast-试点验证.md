# GPU Forecast 30 分钟客户试点

## 试点目标

客户能用自己的或脱敏数据完成一次从数据准备度到待审批采购计划的闭环，并准确解释证据等级、预测区间和风险。

## 30 分钟脚本

1. 0–5 分钟：导入业务历史、资源库存、容量规则，确认数据不会被自动长期保存。
2. 5–9 分钟：找到一个被阻断的范围，说明缺失数据及修复方式。
3. 9–14 分钟：比较季节性朴素、指数平滑、趋势季节模型的滚动回测结果。
4. 14–18 分钟：确认一项业务事件并填写人工调整原因，发布新的不可变预测版本。
5. 18–23 分钟：比较 P50、P90、P99 容量，核对型号和地域没有互相抵扣。
6. 23–27 分钟：检查交付周期、最晚决策日期、预算、配额和证据门禁。
7. 27–30 分钟：导出预测、容量、采购行动 CSV 与管理摘要，并解释主要风险。
